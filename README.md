# xpcDeckTruco - Monorepositório

Projeto de portifólio profissional de um jogo de truco web em typescript usando
arquitetura de microserviços.

![Demonstração](game-demo.gif 'Demonstração')

## Organização

Está sendo usado um monorepo para versionamento visto que é um projeto pessoal
pequeno. A organização do projeto é:

Service - Backend - Microserviços de API Rest.
Interface - Frontend - Página web usando o conceito de sistema de página única.

Cada subpasta de backend e frontend é um subprojeto independente. Mais informações
consultar o readme de cada pasta.
